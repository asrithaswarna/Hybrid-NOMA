### Chapter 1: Introduction
- **1.1 Background & Evolution of Cellular Multiple Access**: Transition from 1G (FDMA), 2G (TDMA), 3G (CDMA), 4G (OFDMA) to 5G/6G non-orthogonal multiple access (NOMA).
- **1.2 Motivation**: Massive connectivity requirements in Beyond 5G (B5G) and 6G IoT networks; limitations of orthogonal spectrum slicing.
- **1.3 Problem Statement**: Combinatorial complexity of dynamic user pairing and resource slot allocation in heterogeneous networks.
- **1.4 Project Objectives**:
  1. Formulate a unified Hybrid NOMA framework combining PD-NOMA and SCMA.
  2. Implement physically consistent channel and interference models with imperfect SIC.
  3. Design an Edge-Conditioned Graph Neural Network for near-optimal real-time pairing and slot allocation.
  4. Perform rigorous experimental evaluation against classical OMA, Random, Near-Far, and Combinatorial Oracle baselines.
- **1.5 Organization of the Report**: Summary of remaining chapters.

---

### Chapter 2: Literature Review & Theoretical Foundations
- **2.1 Fundamentals of Power-Domain NOMA**:
  - Superposition coding principles.
  - Successive interference cancellation (SIC) receiver architectures.
  - Impact of channel gain disparity (near-far effect) on SIC feasibility.
  - Imperfect SIC and residual error propagation.
- **2.2 Fundamentals of Sparse Code Multiple Access (SCMA)**:
  - Multi-dimensional sparse codebook design.
  - Factor graph representations and resource overloading ($\lambda = J/K > 1$).
  - Message Passing Algorithm (MPA) joint multi-user detection.
- **2.3 Hybrid NOMA Architectures**:
  - Rationale for combining PD-NOMA (gain disparity pairs) with SCMA (dense cluster overloading).
- **2.4 Classical User Pairing & Resource Allocation**:
  - Conventional Near-Far pairing, greedy heuristic matching, Hungarian algorithm.
  - Computational complexity bottlenecks in dynamic wireless environments.
- **2.5 Deep Learning & Graph Neural Networks in Wireless Communications**:
  - Why standard MLPs fail (permutation non-equivariance).
  - Graph-based abstraction of wireless cellular topologies.
- **2.6 Research Gaps & Identified Contributions**:
  - Table contrasting existing literature with the proposed GNN framework.

---

### Chapter 3: System Model & Problem Formulation
- **3.1 Cellular Network Topology & Propagation Environment**:
  - Annular disk geometry, base station coordinates, uniform spatial distribution.
  - Log-distance path-loss model and Rayleigh small-scale fading.
- **3.2 Power-Domain NOMA Signal Model**:
  - Transmit signal superposition, power allocation factors ($\alpha_w, \alpha_s$).
  - Weak user decoding and strong user SIC equations with imperfect residual factor $\beta_{\text{SIC}}$.
  - Individual and pair achievable rate derivations.
- **3.3 Sparse Code Multiple Access (SCMA) System Model**:
  - Indicator matrix $\mathbf{F}_{4 \times 6}$ and regular degree properties ($d_v=2, d_f=3$).
  - Complex constellation codebooks and transmitted symbol mappings.
  - Iterative MPA probability updates between variable and factor nodes.
- **3.4 Dynamic Slot Assignment Model**:
  - Partitioning system bandwidth into $S$ orthogonal slots.
  - Power budget constraints and slot capacity limits.
- **3.5 Mathematical Optimization Problem Formulation**:
  - Objective function: Joint Sum-Rate and Jain's Fairness utility maximization.
  - Hard physical constraints: Disjoint pairing, slot capacity, minimum rate thresholds.

---

### Chapter 4: Proposed GNN-Based Dynamic Pairing Architecture
- **4.1 Graph Abstraction of Wireless Networks**:
  - Nodes: Active UEs; Edges: Channel interference and pairing candidates.
  - Node feature engineering (6D vector: spatial coordinates, normalized distance, channel gains, QoS rate).
  - Edge feature engineering (4D vector: Euclidean distance, channel gain disparity, correlation, interference potential).
- **4.2 Edge-Conditioned Message Passing Neural Network**:
  - Multi-layer message extraction, degree-normalized neighborhood aggregation, residual connections, LayerNorm.
- **4.3 Dual-Task Prediction Heads**:
  - Bilinear symmetric edge-scoring head for pair affinity prediction $\hat{\mathbf{A}} \in [0, 1]^{N \times N}$.
  - Multi-layer perceptron head for user slot preference classification $\hat{\mathbf{S}}$.
- **4.4 Combinatorial Supervision Oracle**:
  - Exhaustive search formulation for small networks ($N \le 10$).
  - Edmonds' Blossom maximum-weight matching for scalable topologies ($N > 10$).
- **4.5 Loss Function & Class Balancing**:
  - Positive-weighted Binary Cross-Entropy (BCE) combined with slot Cross-Entropy.
- **4.6 Constraint-Preserving Matching Post-Processor**:
  - Deterministic conversion from continuous probabilities to discrete disjoint pairs.
  - Strict zero-duplicate guarantee and odd-user handling mechanism.
